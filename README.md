# 🗄️ SQL Database Practice

Projeto desenvolvido para praticar conceitos de SQL, incluindo criação de tabelas, inserção de dados, consultas e relacionamentos entre tabelas.

---

## 🚀 Tecnologias

- SQL
- MySQL

---

## ⚙️ Funcionalidades

✔ Criação de tabelas com `CREATE TABLE`  
✔ Inserção de dados com `INSERT INTO`  
✔ Consultas com `SELECT`  
✔ Filtragem de dados com `WHERE`  
✔ Relacionamento entre tabelas com `INNER JOIN`  
✔ Atualização de registros com `UPDATE`  
✔ Exclusão de registros com `DELETE`  
✔ Utilização de chaves primárias e estrangeiras  

---

## 🗄️ Sobre o projeto

O projeto consiste em um banco de dados acadêmico com tabelas de alunos, professores, cursos, departamentos e matrículas.

O objetivo é praticar comandos SQL e compreender como organizar, consultar e relacionar informações em um banco de dados.

---

## 🛠️ Estrutura do projeto

- `database.sql` — Arquivo contendo a criação das tabelas, inserção de dados e consultas SQL.
- `README.md` — Documentação do projeto.
- `.gitignore` — Arquivo para ignorar arquivos desnecessários no Git.

---

## ▶️ Como executar

1. Clone o repositório:

```bash
git clone URL_DO_SEU_REPOSITORIO
```

2. Abra o arquivo `database.sql` em um ambiente compatível com SQL, como MySQL Workbench.

3. Execute os comandos para criar as tabelas, inserir os dados e realizar as consultas.

---

## 📚 Aprendizados

Durante este projeto, foram praticados:

- Fundamentos de SQL.
- Criação e organização de tabelas.
- Inserção e manipulação de dados.
- Consultas e filtros.
- Relacionamentos entre tabelas.
- Utilização de chaves primárias e estrangeiras.
